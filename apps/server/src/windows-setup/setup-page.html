Dispatch setup

Welcome to Dispatch

Dispatch is a local control plane for AI coding agents. This setup checks that PostgreSQL is available, installs Dispatch to %LOCALAPPDATA%\Dispatch, and starts it.

Nothing here needs administrator rights.

PostgreSQL isn't running on this machine

Dispatch stores its data in PostgreSQL. Install it from the official Windows installer, keep the default port, and come back here.

Remember the password you choose for the postgres user.

Connect to PostgreSQL

PostgreSQL is running. Enter the password you chose for the postgres user. Dispatch creates its own dispatch user and database; this password is used once and never stored.
